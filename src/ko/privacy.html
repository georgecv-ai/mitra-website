제5조 (제3자 제공)

학생 정보는 서비스 제공에 필요한 범위 내에서만 공유합니다:

  • Anthropic — AI 모델 제공업체. 튜터링 응답 생성을 위해 학습 프로필과 대화 내용을 수신하며, 오직 당사를 대신하여 처리합니다. API 데이터를 모델 학습에 사용하지 않습니다.
  • Google (Firebase Cloud Messaging) — Android 기기로 앱 알림을 전달합니다. 기기의 푸시 토큰과 알림 내용을 수신합니다.
  • Apple (Push Notification service) — iPhone 및 iPad로 앱 알림을 전달합니다. 기기의 푸시 토큰과 알림 내용을 수신합니다.
  • Twilio — SMS 메시지 전달 (학부모 OTP 인증). 전화번호와 메시지 내용을 수신합니다.
  • KakaoTalk (카카오) — 메시지 전달 (한국 주 채널). 공식 채널 웹훅을 통해 카카오 사용자 ID와 메시지 내용을 수신합니다.
  • Telegram — 메시지 전달. 사용자 ID와 메시지 내용을 수신합니다.
  • Railway — 클라우드 호스팅 (SOC 2 Type II 인증).

학생 데이터를 판매하거나 광고주 또는 데이터 브로커와 공유하지 않습니다.

제6조 (AI 처리 및 동의)

미트라의 튜터링은 Anthropic의 AI 모델인 Claude로 구동됩니다. 자녀의 메시지와 학습 프로필은 튜터링 응답 생성을 위해 Anthropic에 전송됩니다. Anthropic은 이 데이터를 서비스 제공 목적으로만 처리하며 모델 학습에 사용하지 않습니다. Anthropic은 채팅 데이터를 최대 30일간 보관하며, 안전 시스템에 의해 표시된 내용은 안전 및 법적 준수를 위해 더 오래 보관될 수 있습니다.

자녀의 첫 채팅 이전에 — 등록 시 또는 자녀의 앱·웹 접근 생성 시 — 이 처리에 대한 명시적 동의를 받습니다. 학부모 포털에서 자녀의 접근을 초기화하거나, 계정을 삭제하거나, support@mitratutor.com으로 연락하여 언제든지 동의를 철회할 수 있으며, 철회 시 이후의 모든 AI 처리가 중단됩니다.

미트라의 모든 응답은 채팅 안에서 바로 신고할 수 있습니다. 신고된 응답은 당사 팀의 담당자가 검토하며, 통상 24시간 이내에 처리됩니다.
